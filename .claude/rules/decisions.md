# Architecture decision records

- Use the template in `docs/decisions/README.md`, the next unused number, and add the ADR to the index table there.
- Accepted ADRs are history. To change a decision, write a new ADR that supersedes it, and set the old one's status to `Superseded by NNNN`.
- Keep each ADR to about one screen: context, decision, consequences.
- When an ADR changes behaviour, update the affected sections of DESIGN.md, ARCHITECTURE.md, PLAN.md or AGENTS.md in the same change.
